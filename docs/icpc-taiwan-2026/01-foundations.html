1. Template ที่ใช้ทุกข้อ

ใน ICPC พิมพ์ template ซ้ำทุกข้อ ดังนั้นต้องสั้นพอจะพิมพ์ในไม่กี่วินาที และไม่มี macro แปลกๆ ที่เพื่อนร่วมทีมอ่านไม่ออก

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;

    ll ans = 0;
    // ... แก้โจทย์ตรงนี้
    cout << ans << '\n';   // ใช้ '\n' ไม่ใช่ endl (endl flush ทุกครั้ง ช้ามาก)
}
Compile flags ตอนซ้อม ใช้ g++ -std=c++17 -O2 -Wall -Wextra -fsanitize=address,undefined -D_GLIBCXX_DEBUG a.cpp ตอนทดสอบบนเครื่องตัวเอง — จับ out-of-bounds, signed overflow และ iterator ผิดได้ทันที (ไม่ต้องเปิดตอน submit) บน Windows/MinGW sanitizer อาจใช้ไม่ได้ ให้ใช้ WSL หรือแค่ -D_GLIBCXX_DEBUG

2. Complexity budget

กฎหยาบ: C++ ทำ operation ง่ายๆ ได้ประมาณ 108 ครั้งต่อวินาที ดู constraint ก่อนคิดวิธี — constraint คือ hint ที่ใหญ่ที่สุดในโจทย์

n สูงสุดComplexity ที่ยอมรับได้เทคนิคที่มักเป็นคำตอบ
≤ 10–11O(n!)ลองทุก permutation
≤ 20–25O(2n·n)subset/bitmask, bitmask DP
≤ 40O(2n/2)meet in the middle
≤ 500O(n3)Floyd–Warshall, interval DP
≤ 5 000O(n2)DP 2 มิติ, ลองทุกคู่
≤ 2·105 – 106O(n log n) หรือ O(n)sort, binary search, segment tree, two pointers
≥ 109O(log n) หรือ O(√n)สูตร, binary search, fast power, matrix power
ถ้ามี หลาย test case ให้ดูว่าโจทย์รับประกัน "ผลรวม n ทุกเคส ≤ ..." หรือไม่ ถ้าไม่มี ต้องคูณจำนวนเคสเข้าไปด้วย และอย่า memset array ขนาด 106 ทุกเคส

3. Overflow & ชนิดข้อมูล

  • int เก็บได้ประมาณ ±2.1·109, long long ประมาณ ±9.2·1018 — ถ้าผลรวม/ผลคูณอาจเกิน 2·109 ใช้ long long ไปเลย
  • int a = 1e9, b = 1e9; long long c = a * b; ผิด เพราะคูณเป็น int ก่อน ต้องเขียน 1LL * a * b
  • accumulate(v.begin(), v.end(), 0) สะสมเป็น int — ใช้ 0LL
  • v.size() เป็น unsigned: v.size() - 1 เมื่อ v ว่างจะได้เลขมหาศาล ใช้ (int)v.size()
  • ค่า infinity: const ll INF = 4e18; ระวัง INF + w overflow → ใช้ 1e18 หรือเช็คก่อนบวก
  • เกิน long long แต่ไม่เกิน ~1.7·1038: __int128 (พิมพ์ออกเองต้องแปลงเป็น string)
  • Floating point: ใช้ long double และหลีกเลี่ยงถ้าทำเป็นจำนวนเต็มได้ (เช่น เปรียบเทียบ a/b < c/d ด้วย a*d < c*b) พิมพ์ด้วย cout << fixed << setprecision(10)

4. STL ที่ต้องคล่อง

// sort แบบกำหนดเอง: เรียงจากมากไปน้อย ถ้าเท่ากันเรียงตาม index
sort(v.begin(), v.end(), [](const auto &a, const auto &b) {
    if (a.first != b.first) return a.first > b.first;
    return a.second < b.second;           // comparator ต้องเป็น strict (< ไม่ใช่ <=)
});

// binary search บน vector ที่เรียงแล้ว
int i = lower_bound(v.begin(), v.end(), x) - v.begin(); // ตัวแรกที่ >= x
int j = upper_bound(v.begin(), v.end(), x) - v.begin(); // ตัวแรกที่ >  x
int cnt = j - i;                                         // จำนวนตัวที่ == x

// set / multiset: เรียงตลอด, insert/erase/find O(log n)
multiset<int> ms = {5, 1, 5, 3};
ms.erase(ms.find(5));      // ลบ 5 แค่ตัวเดียว  (ms.erase(5) ลบทุกตัว!)
auto it = ms.lower_bound(4); // ตัวแรก >= 4  → ใช้ ms.lower_bound ไม่ใช่ std::lower_bound (นั่น O(n))
int mx = *ms.rbegin();

// map: นับความถี่ / coordinate compression
map<int,int> freq; for (int x : a) freq[x]++;

// priority_queue: default เป็น max-heap
priority_queue<int> maxpq;
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> minpq; // min-heap สำหรับ Dijkstra

// coordinate compression
vector<int> xs = a;
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
for (int &x : a) x = lower_bound(xs.begin(), xs.end(), x) - xs.begin();

// ลองทุก permutation (ต้อง sort ก่อน)
sort(p.begin(), p.end());
do { /* ใช้ p */ } while (next_permutation(p.begin(), p.end()));
เลือกโครงสร้างข้อมูลยังไง ต้องการ "ตัวที่ใกล้ x ที่สุด" หรือ "ลบ/เพิ่มแล้วยังเรียงอยู่" → set/multiset · ต้องการแค่ "ตัวที่มาก/น้อยที่สุด" → priority_queue (เร็วกว่า) · ต้องการ "นับ/ค้นหา key" → map หรือ array ถ้า key เล็ก (array เร็วกว่า map ประมาณ 10 เท่า)

5. Bit manipulation

(x >> i) & 1          // bit ที่ i ของ x
x | (1 << i)          // set bit i
x & ~(1 << i)         // clear bit i
x & -x                // bit ต่ำสุดที่เป็น 1 (ใช้ใน Fenwick tree)
__builtin_popcount(x), __builtin_popcountll(x)   // จำนวน bit 1
__builtin_ctz(x)      // จำนวน 0 ท้าย (x != 0)
31 - __builtin_clz(x) // floor(log2 x) (x != 0)
1LL << 40             // ต้องใช้ 1LL ถ้า shift เกิน 31

// วนทุก subset ของ n ตัว
for (int mask = 0; mask < (1 << n); mask++)
    for (int i = 0; i < n; i++) if (mask >> i & 1) { /* i อยู่ใน subset */ }

// วนทุก submask ของ mask (รวมทุก mask = O(3^n))
for (int s = mask; s > 0; s = (s - 1) & mask) { /* ... */ }

XOR ใช้บ่อย: a ^ a = 0, prefix xor ใช้หา xor ของช่วงได้เหมือน prefix sum

6. Complete search (brute force)

ถ้า n เล็กพอ brute force คือคำตอบที่ถูกต้องที่สุดและเขียนเร็วที่สุด — และแม้ n ใหญ่ brute force ก็จำเป็นสำหรับ stress test

// backtracking: วาง n queens / เลือกของทีละชิ้น
void rec(int i) {
    if (i == n) { /* ตรวจคำตอบ */ return; }
    for (each choice c) {
        if (!valid(c)) continue;   // pruning ยิ่งตัดเร็ว ยิ่งเร็ว
        apply(c);
        rec(i + 1);
        undo(c);                   // อย่าลืมคืนสถานะ
    }
}

Meet in the middle: n ≈ 40 แบ่งเป็นสองครึ่ง ครึ่งละ 220 subset, enumerate ทั้งสองฝั่ง sort ฝั่งหนึ่งแล้ว binary search/two pointers หาคู่ที่ตรงเงื่อนไข

7. I/O และกับดักรูปแบบ input

  • หลาย test case: reset ตัวแปร global/vector ทุกเคส — bug อันดับหนึ่งใน ICPC
  • อ่านจนจบไฟล์: while (cin >> n) { ... }
  • อ่านทั้งบรรทัด: getline(cin, s) หลังใช้ cin >> ต้อง cin.ignore() ทิ้ง newline ก่อน
  • Output format: ICPC ตรวจเข้มกว่าที่คิดในบางโจทย์ ("Case #1: ...", ช่องว่างท้ายบรรทัด, ตัวพิมพ์เล็ก/ใหญ่ของ "YES") ให้ copy ข้อความจาก sample
  • Interactive problem: ต้อง cout.flush() หรือใช้ endl หลังทุกคำถาม
